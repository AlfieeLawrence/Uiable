# Alerts

Settings → Alerts. Channels: **email**, **Telegram**, **webhook**, **Discord**, **ntfy**. Each channel has a **Test** button.

- Threshold rules for CPU, memory, disk, temperature, container-down
- **Quiet mode** doubles cooldown after each fire until the condition recovers
- **Alert history** lists recent fires in the UI (`alerts-history.jsonl`)
