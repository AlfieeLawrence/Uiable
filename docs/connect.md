# Uiable Connect

[Uiable Connect](https://github.com/AlfieeLawrence/Uiable-Connect) is the companion app (Windows, macOS, Linux/Docker, iOS/Android sideload).

- Save SSH / Telnet / serial connections
- Terminal, SFTP, port forwards
- Open this dashboard through an SSH tunnel
- Install or update Uiable on a server over SSH

Full guides: [Connect documentation](https://github.com/AlfieeLawrence/Uiable-Connect/tree/main/docs) · machine index [`manifest.json`](https://github.com/AlfieeLawrence/Uiable-Connect/blob/main/docs/manifest.json)
